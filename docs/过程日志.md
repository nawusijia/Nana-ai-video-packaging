# 过程日志：我让AI给我的账号做了一整套包装

> 每一步的卡点、原因、解法。拍视频时可直接当脚本素材。

## 起点
- 灵感：小红书 Vincent《盘点opus5.5 制作视频的 15种风格》——画面、动画、音乐、音效全由 Opus 5.5 写代码生成，不接视频模型。
- 原理（四步）：网页代码画动画 → 无头浏览器逐帧截图 → Python 代码合成音乐音效 → ffmpeg 合成视频。

## 难点 1：原作者的开源仓库拉不下来
- 现象：Claude 的工作环境访问 GitHub 需要绑定账号；绑定后依然提示没有访问权限。
- 原因：仓库大概率已被作者改为私有（评论区也有人反映“打不开了”）。
- 解法：不抄作业，让 AI 按同样原理从零搭一套。
- 可讲的点：demo 背后的“仓库”随时可能消失，掌握原理比收藏链接靠谱。

## 难点 2：装不了常用的 Node 渲染库
- 现象：npm 安装 puppeteer 被网络策略拒绝（403）。
- 解法：换路线，用环境里已有的 Python 版 Playwright + 自带的 Chromium 截图。条条大路，换一条就行。

## 难点 3：渲染脚本卡死 30 秒超时
- 现象：脚本一直等“页面准备好”，等到超时。
- 原因：等待条件写的是“动画函数存在”，返回的是函数本身而不是 true/false，判断没生效。
- 解法：改成明确的布尔判断 `!!(...)`，一行修好。

## 难点 4：第一版排版翻车
- 现象：渐变装饰线压在第二行标题上，看着像删除线；副标题挤在一起。
- 原因：AI 写布局时按“一行标题”估的高度，打字动画换行成两行后空间不够。
- 解法：截一帧静态图检查 → 卡片加高、重新分配标题/线/副标题的位置 → 再渲染。
- 可讲的点：**AI 不会自己“看”成片，要截图回看**。这一步就是人（或 AI 自查）的审美把关。

## 成片 v1：娜乌斯嘉AI 片头（6 秒，1920×1080）
- 风格：极光 + 玻璃拟态，深蓝底、薄荷绿/紫渐变，干净理性。
- 动画：背景极光与粒子淡入 → 玻璃卡片上浮 → 标题打字机效果 → 渐变线划出 → 副标题与品牌名淡入 → 淡出。
- 声音（全代码合成）：暖色和弦铺底、卡片上浮的“嗖”声、每个字一声键盘音、渐变线出现时三音铃声、品牌名出现时一串闪光音、低频节拍。
- 渲染耗时：约 2 分钟（180 帧）。

## 难点 5：v1 被评价“像好几个月以前的AI水平”
- 诊断（三条，可直接做成视频里的反面教材）：
  1. 做的是模板不是设计：深蓝渐变+玻璃卡片+打字机，是AI最偷懒的默认审美，没有概念和记忆点。
  2. 几乎不“动”：6秒里只有上浮、打字、划线，是PPT动画，不是动态设计。
  3. 没看参考就动手：只读了原视频的文字，没看画面。
- 解法：换成动态排版（kinetic typography）路线，见 v2。

## 难点 6：内置浏览器放不了小红书视频
- 现象：视频一直停在第一帧，无法逐帧看参考。
- 解法：请人类截图关键帧；同时按动态设计通用原则先做。

## 成片 v2：动态排版版（6 秒，120bpm）
- 设计原则：
  - 一个强概念：开场橙色圆点落地 → 拉成一条线 → 撕开黑幕；结尾黑色圆形吞掉画面 → 落版。首尾呼应。
  - 字是主角：每个词卡在鼓点上从遮罩里“弹”出来，带回弹和倾斜，大小对比极端（“AI”560px vs 角标22px）。
  - 限制配色：米白、墨黑 + 一个强调橙，只在“一整套”用一次蓝。
  - 制作感细节：时间码、REC、刻度尺播放头，像在剪辑软件里。
  - 镜头：全程缓慢推进 + 每个重拍轻微“冲”一下，“包装”落地时屏幕震动。
- 声音：120bpm 底鼓/军鼓/镲，每个词一个和弦点，“包装”前加升调铺垫，落地用低频下潜+大和弦+镲。
- 技术升级：60 帧渲染后两两混合成 30 帧，得到真实运动模糊；截图改 JPEG，渲染从约 2 分钟降到 20 秒。
- 修过的翻车：“AI”顶部被裁、“包装”出画、落版被黑圈盖住——都是截几帧拼成接触表（contact sheet）一眼查出来的。

# 案例二：原理流程图动画

## v1
- 需求一句话：做个动画讲清楚这套原理（网页画动画→逐帧截图→代码合成音乐→ffmpeg出片）。
- 结果：深蓝底、四个天蓝描边方框、箭头依次长出，像说明书。

## 娜乌斯嘉的反馈（提炼）
- 颜色单调；动效约等于没有；像死板的课件。
- 关键一句：我是活泼可爱型的女性AI博主，AI圈全是男科普博主。

## AI 的诊断
1. 配色是默认的“科技蓝”，没有品牌色。
2. 原理图该讲“流动和变形”，v1 只是四个静止盒子。
3. 根本原因：AI 不知道博主是谁，就按“科普说明书”的平均人设做了。
- 教训：**告诉 AI 你是谁。不给人设，它就给你平均值。**

## v2 改了什么
- 人设落地：奶油底+糖果色（粉、黄、薄荷、浅紫）+深色粗描边，贴纸风，所有东西都会回弹和晃。
- 叙事：一个圆滚滚的“小AI”吉祥物沿弯弯的路线一站一站蹦过去，每到一站东西“变身”：网页里出现一颗心 → 相机“咔嚓”吐出胶片 → 代码括号蹦出音符 → 播放键撒彩纸“出片啦！”。
- 动画原理：起跳前下蹲预备、空中拉长、落地压扁回弹（挤压与拉伸），图标被踩时果冻抖动，吉祥物会眨眼。
- 声音：马林巴琴似的拨弦和弦、蹦跳“boing”、落地 pop、快门声、彩纸噼啪、收尾“哒哒”。

## 难点 7：图标和吉祥物全部不显示
- 现象：第一次截图只有标签和虚线，所有图标、吉祥物都不见了。
- 原因：内嵌 SVG 的尺寸写成了 0×0，浏览器直接跳过不画（哪怕设置了溢出可见）。
- 解法：尺寸改成 1×1，内容照常溢出显示。又是截图接触表一眼看出来的。

## 难点 8：音符飘上去撞到标题
- 解法：压低上升高度。

# 案例三准备：口播 + 花字

## 难点 9：AI 听不见声音（没有语音识别）
- 现象：工作环境里没有语音识别工具；常用的模型下载站（Hugging Face、ModelScope、OpenAI）和 pip 都被网络白名单拦住。
- 解法：发现 GitHub 能通，而环境里自带 ONNX 推理库。从 GitHub 的开源项目发布页下载中文 Paraformer 模型，自己用 numpy 写了音频特征提取和解码，几十行代码跑起来，还能按停顿切句给出时间轴。
- 效果：小模型错字多；换大模型后明显好转，但专有名词（产品名、“娜乌斯嘉”）仍会听错，需要人工校对或提供热词。
- 可讲的点：**“装不上”不等于“做不到”，让 AI 自己找另一条路。**

## 难点 10：参考视频按秒计费
- Seedance 2.5 的参考视频时长也计入费用，把 10 秒参考剪成 5 秒和 3 秒两版做对比测试。

## 难点 11：文件传不上 libTV
- 现象：AI 的工作环境不允许直接往 libTV 的云存储上传文件。
- 原因：Claude 聊天里“设置 → Capabilities → Allow network egress”的域名白名单。娜娜把它改成 All domains 后立刻生效，模型网站和 libTV 存储都通了，文件成功上传。
- 新坑：通过插件建的视频节点，生成预检不认它当参考（提示没有可用的 url）。
- 定位方法：读娜娜以前手工做的画布，对比节点数据结构，发现视频地址要写成列表 ["网址"]，而不是单个字符串。
- 解法：按正确格式重建节点，预检通过。全程不需要人在电脑旁边。
- 可讲的点：**工具报错时，让 AI 去找一个“能用的样本”对照，比瞎猜参数快得多。**

## 口播测试：5 秒参考 vs 3 秒参考（Seedance 2.5 样片模式，480P，10 秒）
- 台词：“左边和右边，是同一个AI、同一个下午做的片头。中间我只干了一件事：骂了它一句丑。”
- 两条都一次成功；AI 用语音识别回听，两条台词都念对了（识别器把“丑”听成“愁”一次，是识别器的错）。
- 长相、白T、猫耳发箍、娃娃墙都保留住了。
- 3 秒参考那条节奏更好：句子之间有停顿，“丑”字配了嫌弃脸和手势；5 秒那条一口气念完。
- 结论：3 秒参考就够用，还更省积分。音色像不像只能人来听，AI 判断不了。

## 难点 12：动作太夸张 → 写具体动作后，模型把动作说明里的词念了出来
- 第一版提示词只写了“活泼可爱、表情丰富、自然手势”，模型自由发挥，“丑”字配了夸张鬼脸。
- 第二版写了具体动作并要求幅度小，表情确实收住了，但动作说明里带引号的“左边”“右边”被模型当成台词又念了一遍。
- 解法：动作说明里不要再引用台词原文，改成“说第一句时……”“说最后一句时……”。
- 可讲的点：**提示词里带引号的字，模型可能当台词念；台词只出现一次。**
- 另：调色把参考片的高光和中间调压下去，生成结果也跟着不过曝了。
- 娜娜的规矩：**不要完全相信视频模型，它经常说错、多说、少说。** 多说的可以剪掉；拿不准的地方停下来等人定夺。
- 本条处理：用语音识别找到多念的“左边、右边”所在时间段（约 4.4–6.3 秒），直接剪掉，回听确认台词完整。

# 案例三：花字

## v1
- 需求一句话：给口播加花字（用即梦生成的开场白口播）。
- 结果：底部白字粗黑边字幕；头顶弹出黄、红大字“全程由Claude生成！”“我负责吐槽！”，红字还抖。

## 娜娜的原话
- “很难想象这是Claude做的字幕包装，土到我奶奶都不想看一眼！”

## AI 的诊断
1. 套了最土的默认模板：白字粗黑边 + 黄红大字 + 感叹号 + 抖动，是“花字”这个词的平均值。
2. 花字只是把字幕重复一遍，同一句话在屏幕上出现两次，没有多给观众任何信息。
3. 最要命：案例二刚定下的品牌（糖果色、深色描边贴纸、小AI吉祥物），到案例三全忘了，又从零开始。
- 教训：**做对一次之后，让 AI 把规矩写下来变成品牌规范，下次自动用。AI 不会自己记住上次学到的东西。**

## v2 改了什么
- 先写《娜乌斯嘉AI_品牌规范》（颜色、形状、字、动效、吉祥物、声音、不挡脸），再按规范做。
- 字幕：奶油色胶囊条 + 深莓墨字，正在说的字变粉，关键词底下有奶黄荧光笔。
- 花字只写“第二层”：“全程 Claude 出品 / 口播也是AI做的哦”“？”气泡、“吐槽担当 / 本期唯一人类工作量”，不重复字幕。
- 小AI吉祥物在“全程由Claude生成”时从右下角探头，问“干了啥”时歪头，说“吐槽”时蹦起来。
- 音效：探头 boing、贴纸 pop、盖章声、闪光音。
