# 口播生成提示词模板（参考生视频）

参考视频：博主过往口播 3 秒片段（先调色，避免过曝）。720P，16:9，开声音。

```
参考视频中的同一位女生，同样的发型、<服装>、<配饰>，坐在同样的<背景>前，正面中景对着镜头说话，声音和语气与参考视频一致，语气<轻松自然、带一点俏皮>。她用普通话只说下面这一段台词，不增不减："<台词>"
动作和表情：<用“说第一句时”“说最后一句时”描述动作；不要在这里引用台词原文>。整体动作幅度小，不夸张，不做鬼脸。
固定机位，自然室内光，画面明暗正常，不过曝。
```

## 动作写法示例（按娜娜的习惯）
| 场合 | 动作 |
| --- | --- |
| 数第几个案例 | 开头竖起一根/两根/三根手指 |
| 反问吐槽 | 微微挑眉、轻轻歪头，可爱的不服气 |
| 开心小结 | 开心地笑，双手在胸前轻轻合拍一下 |
| 揭秘 | 身体微微前倾，单手指一下自己，最后眨眼 |
| 收尾 | 对镜头挥手，笑着 |

## 时长
时长 ≈ 字数 ÷ 4 + 1～2 秒。单段 ≤ 30 秒。
