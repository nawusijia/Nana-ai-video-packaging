# 娜乌斯嘉AI · 视觉包装规范

> 定位：AI 圈少有的活泼可爱型女博主。不做“男科普博主”的冷色说明书风。
> 每次做包装（片头、图解、花字、片尾）先读这份。

## 颜色
| 用途 | 色值 |
| --- | --- |
| 底色 / 贴纸底 | 奶油 #FFF4EA |
| 描边、投影、正文字 | 深莓墨 #3B2340（不用纯黑） |
| 主强调 | 糖果粉 #FF6FA8 |
| 辅助 | 奶黄 #FFD84D、薄荷 #5FD3B3、浅紫 #B9A7FF、蜜桃 #FFB38A |

一屏最多同时出现 3 种强调色。不用红色、纯黄、纯黑。

## 形状
- 贴纸感：圆角大（胶囊或 26–40px 圆角），5–6px 深莓墨描边，右下 6–10px 实色投影。
- 元素可以有 3–8° 的歪斜，像随手贴上去的。

## 字
- 思源黑体 Heavy/Black，正文 深莓墨，不加黑色粗描边。
- 感叹号少用。花字写“态度和梗”，不重复字幕原文。

## 动
- 进场：回弹（冲过头再弹回）+ 小幅摇摆衰减。
- 出场：缩小或下沉，0.2–0.3 秒。
- 节奏：动作对齐说话的停顿或鼓点。
- 禁止：生硬抖动、匀速滑入、PPT 式淡入淡出。

## 吉祥物「小AI」
- 粉色圆团，深莓墨描边，头顶天线挂黄色星星，粉腮红，会眨眼。
- 可以探头、蹦跳、冒问号气泡、举牌子。用于串场和给花字“配反应”。

## 声音
- 背景音乐：**科技感 + 一点点活泼**。电子合成器琶音、干净的电子鼓、低音脉冲，偶尔点缀铃音。不用马林巴/尤克里里这类“幼儿园”音色。
- 音量：比人声低约 11 LU（人声约 -15 LUFS，音乐约 -26 LUFS），说话时自动压低；全屏看片时音乐让位给原声。
- 音效：贴纸 pop、清单叮、转场“嗖”、印章“啪”（要响、要脆）。

## 剪辑节奏
- 句间停顿压到约 0.3 秒；每个“骂之后”的作品要有一段全屏原片原声，留给观众安静看。
- 开头 2 秒内必须有强画面 + 悬念标题，反转放第二拍。
- 吐槽印章在吐槽说完后盖，位置在作品画面右上角，不压作品里的文字。
- 标签用“骂之前 / 骂之后”。

## 口播画面里
- 不挡脸：花字和贴纸放在画面左右两侧或下方，人物脸部区域留空。
- 字幕用奶油色胶囊条 + 深莓墨字，正在说的字变粉。

## 平台安全区
- **画面右侧约 1/6 留空**：小红书等平台的点赞、评论、分享按钮在右边，会挡住内容。
- 头像小窗、吉祥物、重要贴纸一律放左侧（左下优先，左上次之）。
